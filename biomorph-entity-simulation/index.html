Biomorph Entity Simulation

Date 03 December 2009

The Biomorph Entity program simulates a virtual creature. From experimenting with simple rules that govern the interaction of the segments, the computer simulation developed an emergent behaviour of the collective. In the future, I may add genes to express the discreet rules and in using genetic programming techniques bring evolution to the virtual environment, as I did in my microbial simulation program, Microbe. This should allow experimentation to evolve novel biomorphs. The program was written in Python programming language and Pygame multimedia library. The Biomorph Entity program can be found on my projects page, and a video clip of the simulation is on my demo videos page.
